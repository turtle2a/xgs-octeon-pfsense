pfSense CE on the Sophos XGS 2300

An open-source FreeBSD kernel driver, xgs_octep, for the OCTEON TX network processor (PCI 177d:a300) in the Sophos XGS 2300. It lets pfSense CE use the front ports as octepN interfaces. The driver is rewritten from our own Linux OCTEP driver and is licensed GPL-2.0-or-later.

Sophos XGS models

These four Sophos XGS firewalls use the same OCTEON TX NPU family. Only the XGS 2300 has been tested with pfSense CE; the others are inferred from the vendor spec files, so treat them as untested.

Quick start

  1. Install pfSense CE from the serial memstick image: write it to a USB stick, boot the XGS from it over a serial console, and install onto the disk you will use permanently.
  2. Copy the project to the firewall and run, as root: 
    /bin/sh ./install.sh
  3. Reboot. The NPU takes 1 to 3 minutes to answer. Check: 
    /sbin/sysctl dev.xgs_octep.0.status
  4. Configure NAT, firewall and routing as on any pfSense install.

Full steps, loader tunables and recovery are in the README.
